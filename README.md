# Yemenia Ticket OCR

مشروع Render مستقل لمسح تذاكر طيران اليمنية واستخراج بيانات المسافر والرحلات.

## التشغيل على Render

ارفع مجلد المشروع إلى GitHub، ثم أنشئ **Web Service** واختر:

- **Runtime:** Python
- **Build command:** `pip install -r requirements.txt`
- **Start command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
- **Health check:** `/health`

يمكن استخدام `render.yaml` لإنشاء الإعدادات تلقائيًا. ملف `apt.packages` يثبت Tesseract وبيانات العربية والإنجليزية في بيئات Render التي تدعم Aptfile/apt.packages.

بعد النشر افتح رابط الخدمة نفسه؛ الواجهة موجودة في `/` والـAPI في `/extract-document/`.

## الحقول المستخرجة

الاسم، رقم التذكرة، رقم الحجز PNR، شركة الطيران، مسار الرحلة، المطارات، أرقام الرحلات، التاريخ، وقت الإقلاع والوصول، الأمتعة، نوع الرحلة، والرحلة المفتوحة OPEN عند ظهورها في التذكرة.

النتيجة آلية ويجب مراجعتها مقابل التذكرة الأصلية، خصوصًا رقم التذكرة ووقت الرحلة.
